# Helleristninger Weekly Release `v2026.W48`

This directory holds the frozen weekly release snapshot (`v2026.W48`, 2026-11-28) of the Nordic Helleristninger Scientific Corpus and 750-Piece Production Consolidation.

## Contents

- [`RELEASE_MANIFEST.json`](./RELEASE_MANIFEST.json) — SHA-256 checksums and byte sizes for every file in this release.
- [`CITATION.cff`](./CITATION.cff) — Standard citation metadata (CFF 1.2.0) including primary Scandinavian rock-art literature references.
- [`datapackage.json`](./datapackage.json) — Frictionless Data Package descriptor linking the scientific record, gazetteer, QA audit, findings, and 750-piece catalog.
- [`CHANGELOG.md`](./CHANGELOG.md) — Release notes for `v2026.W48`.
- `data/` — Frozen snapshot of `figures.jsonl`, `figures.csv`, `schema.json`, `site_gazetteer.json`, `literature.json`, `taxonomy.json`, `dual_trace_report.json`, `dual_trace_disagreements.jsonl`, `findings_metrics.json`, `findings_v2026.W48.md`, `selected-750-catalog.json`, `rights-inventory.csv`, and 750-piece production/fidelity/provenance audits.
- `figures/` — Publication-grade figures generated by `helleristninger/science/analyze_corpus.py`.
