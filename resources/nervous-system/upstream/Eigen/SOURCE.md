# Eigen 3.3.4

Nervous System credits Eigen for matrix operations in its October 24, 2017 article about the Maze puzzle. The studio leaves its exact version unspecified. Eigen released 3.3.4 on June 15, 2017, and the next maintenance release, 3.3.5, followed in July 2018. [Studio credit](https://n-e-r-v-o-u-s.com/blog/?p=7821) · [Eigen 3.3.4 announcement](https://libeigen.gitlab.io/news/eigen_3.3.4_released/) · [Release tags](https://gitlab.com/libeigen/eigen/-/tags)

The [local archive](eigen-3.3.4.tar.bz2) is the complete source download linked from the release announcement. It includes the core C++ headers, tests, documentation, demos and unsupported modules. The archive’s embedded commit ID matches the upstream tag, and the header `Eigen/src/Core/util/Macros.h` identifies version 3.3.4. All 1,609 regular files were readable after decompression.
