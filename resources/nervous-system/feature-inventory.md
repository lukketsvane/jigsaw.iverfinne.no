# Generative jigsaw feature inventory

Reviewed November 28, 2026. The studio’s custom maker lists six cut families. Its project archive and shop also document puzzles with different rules for tiling, artwork, assembly and fabrication. The tables group editions that share a mechanism. Each row identifies the local implementation or the specific capability still missing. [Custom maker](https://n-e-r-v-o-u-s.com/customPuzzle/) · [Jigsaw project archive](https://n-e-r-v-o-u-s.com/projects/puzzles/) · [Puzzle catalog](https://n-e-r-v-o-u-s.com/shop/line.php?code=12)

## Run the workshop

From the repository root, run `.\.venv\Scripts\python.exe -m dendrite_engine serve` and open [Formverk Studio](http://127.0.0.1:8765/). Upload a photo or generate artwork, choose the outline and cut, place figures or glyphs, try the puzzle and download its cut and print files. Open [Puzzle editions](http://127.0.0.1:8765/editions.html) for the four Infinity surfaces, Spectre, the polyhex game, two assemblies, nested bubbles, Eclipse and chess. Each edition exposes a seed, a preview and downloadable production or game files. With the project environment active, the same generators run from the command line.

```powershell
python -m dendrite_engine generate --style coral --outline organic --width-mm 130 --height-mm 100 --pieces 12 --seed 117 --whimsy glyph:B:0.5,0.5,21 --auto-place-whimsies --artwork-pattern geode --title "Geode study" --reverse-text "PUZZLE 117" --out runs/dendrite-engine/coral-geode-117
python -m dendrite_engine infinity --topology sphere --frequency 2 --out runs/editions/sphere
python -m dendrite_engine spectre --depth 2 --out runs/editions/spectre
python -m dendrite_engine polyhex --seed 42 --missing 12 --out runs/editions/polyhex
python -m dendrite_engine dual --out runs/editions/dual
python -m dendrite_engine eclipse --out runs/editions/eclipse
python -m dendrite_engine nested --out runs/editions/nested
python -m dendrite_engine chess --out runs/editions/chess
python -m dendrite_engine parts runs/dendrite-engine/coral-geode-117 --ids 0 2 --out runs/editions/recut
```

For an outline derived from a photograph, use `--outline photo --artwork path/to/photo.png`. For mixed cuts, pass `--regions path/to/regions.json`. Each region uses normalized board coordinates. Its piece count contributes to the total specified by `--pieces`. This 16-piece layout assigns one side to Coral and the remainder to Matrix.

```json
[
  {"style":"coral","pieces":8,"points":[[0,0],[0.55,0],[0.42,1],[0,1]]},
  {"style":"matrix","pieces":8,"remaining":true}
]
```

The fabrication audit reports geometry measurements. The custom generator returns exit code 2 when a design misses a digital gate. A straight regional boundary can let an entire group slide away even when its individual pieces interlock.

## Physical products and services

Local [frame exports](../../pathnet/frame_export.py) produce a ring or strips and a backing cut for supported boards. The studio also offers transparent double-sided display frames and uses puzzle-specific IDs to produce replacement pieces. Formverk saves digital geometry that could support those services. The [parts command](../../dendrite_engine/parts.py) exports a replacement by saved piece ID with registered print and a hash of its original board. Customer ordering, manufactured frames and physical fit trials require additional operations. The archive includes the studio’s separately released air-assist nozzle. [Frames](https://n-e-r-v-o-u-s.com/shop/product.php?code=441) · [Replacements](https://n-e-r-v-o-u-s.com/shop/product.php?code=417) · [Nozzle release and verification](fabrication/air-assist/SOURCE.md)

The Puzzle Cell Lamp is an adjacent 3D fabrication experiment. It optimizes a curved surface into flattenable veneer panels, generates openings within each panel and adds physical joints. A planar jigsaw and an icosahedral map net address different engineering requirements. The studio’s lamps, jewelry, garments and installations are catalogued separately from its jigsaw range.
